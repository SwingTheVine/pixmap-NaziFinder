# NaziFinder
This version of the script finds patterns on Wplace. It was designed to detect swastikas, so they can be reported manually.

## Disclaimer
This version of the script is highly unstable, has issues stopping, and producing zombie/orphan processes during exceptions & interuptions. Run at your own risk.
This script was made to be run only once by SwingTheVine, so there is no documentation for it yet. You can run `py main.py` or `py main.py --help` for information on flags.
